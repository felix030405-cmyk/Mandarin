Master Data (Dictionary)
Arsip lengkap, independen dari Master Data Tes. Satu Master Data ini jadi sumber untuk sub-tab KATA dan KARAKTER di bawah, dan untuk "Kata lainnya" yang muncul di kunci jawaban Pilgan/Tes Card/Karakter. Format sama: Hanzi - Pinyin - Arti.
Backup
Export/Import sekaligus mencakup Master Data (Tes), Master Data (Dictionary), dan seluruh struktur Kategori. Import akan MENIMPA TOTAL semua data yang ada sekarang.
Cloud Sync
Simpan/ambil semua data (Tes, Dictionary, Kategori) dari cloud. Ketik kodemu di bawah: data tiap kode tersimpan terpisah, jadi tidak tercampur dengan orang lain. Kode diingat di browser ini dan bisa diganti kapan saja. Pilih kode yang mudah diingat tapi tidak mudah ditebak. Butuh internet.
